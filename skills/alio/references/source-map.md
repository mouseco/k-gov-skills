# ALIO 출처 맵

## 공식 사이트

- ALIO 공공기관 경영정보 공개시스템: http://www.alio.go.kr/
- ALIO 오픈데이터: https://opendata.alio.go.kr
- JOB-ALIO: https://job.alio.go.kr/
- ALIO PLUS: https://www.alioplus.go.kr

## 사이트별 역할

### ALIO 본공시

사용할 때:
- 공공기관의 경영공시 원자료를 확인할 때
- 기관 일반현황, 임직원, 재무, 예산, 주요사업, 평가, 감사 정보를 확인할 때
- 보고서에 넣을 공식 근거가 필요할 때

확인할 값:
- 기관명
- 기관유형
- 소관부처
- 기준연도
- 공시차수 또는 공시일
- 공시 항목명
- 수치 단위와 기간
- 원문 또는 상세 페이지 URL

### ALIO 오픈데이터

사용할 때:
- 여러 기관의 공시 항목을 데이터 형태로 비교할 때
- 반복 조회나 표준화된 데이터 추출이 필요할 때
- 보고서용 비교표의 기초자료가 필요할 때

확인할 값:
- 데이터셋명
- 제공 항목
- 갱신 주기
- 기준연도
- API 또는 다운로드 방식
- 이용 조건

### JOB-ALIO

사용할 때:
- 공공기관 채용 공고 원문을 확인할 때
- 기관별 채용 현황, 접수기간, 직무, 고용형태를 확인할 때

확인할 값:
- 기관명
- 공고명
- 접수기간
- 채용분야
- 고용형태
- 공고 원문 URL
- 첨부파일 여부

### ALIO PLUS

사용할 때:
- 국민 대상 행사, 시설, 사업, 기관 안내를 보조적으로 찾을 때
- ALIO 본공시보다 생활정보·서비스 안내가 필요한 경우

주의:
- ALIO PLUS는 본공시가 아니라 보조 탐색 출처로 둔다.
- 경영공시와 수치 판단은 ALIO 본공시나 오픈데이터로 보강한다.

## 메뉴 선택 기준

### 기관 현황 조사

1. ALIO 본공시에서 기관 기본 정보를 확인한다.
2. 기관 공식 홈페이지로 최신 조직·사업 설명을 보강한다.
3. 필요하면 ALIO PLUS 기관 안내를 보조로 확인한다.

### 재무·인력·임원·사업 비교

1. ALIO 본공시의 같은 항목, 같은 기준연도 자료를 사용한다.
2. 여러 기관 비교는 ALIO 오픈데이터 사용 가능성을 먼저 확인한다.
3. 수치 단위와 기간을 통일한다.

### 채용 확인

1. JOB-ALIO에서 공고 원문을 확인한다.
2. 기관 채용 페이지 또는 첨부 공고문으로 세부 조건을 확인한다.
3. 마감 공고와 진행 중 공고를 구분한다.

## 검색어 만들기

- 기관명은 정식 명칭과 약칭을 모두 시도한다.
- 기관명이 바뀐 경우 과거 명칭도 확인한다.
- 비교 조사는 `기관명 + 공시항목 + 기준연도` 순서로 좁힌다.
- 채용은 `기관명 + 공고명`보다 JOB-ALIO 기관 검색을 우선한다.

## 결과 해석 주의

- ALIO 공시자료는 기준연도와 공시 시점이 중요하다.
- 기관별 회계·사업 구조 차이 때문에 단순 수치 비교는 오해가 생길 수 있다.
- 자료가 수정공시 되었는지 확인한다.
- ALIO PLUS 자료를 ALIO 경영공시처럼 표현하지 않는다.
