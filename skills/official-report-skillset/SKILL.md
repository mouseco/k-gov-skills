# official-report-skillset

공공기관 보고서는 글을 예쁘게 만드는 작업이 아니라, 결재권자가 빠르게 판단할 수 있게 구조를 잡는 작업이다.

기본 순서는 아래와 같다.

```text
1. 문서 목적 확인
2. 보고서 유형 판정
3. 상위 목차 단순화
4. 세부 내용을 주요 내용 아래로 배치
5. 결재 문체로 초안 작성
6. 근거·일정·책임·붙임 점검
```

## 1. 기본 원칙

- 결론과 보고 목적이 첫 문단에서 보여야 한다.
- 상위 목차는 가능한 한 적게 둔다.
- 세부 쟁점은 상위 목차를 늘리지 말고 `주요 내용` 아래로 넣는다.
- 사실, 판단, 계획, 요청사항을 섞지 않는다.
- 확인되지 않은 날짜, 수치, 법령명은 단정하지 않고 `확인 필요`로 남긴다.

## 2. 목차 기본값

공공기관 내부 결재문서의 기본 상위 목차는 아래 순서를 우선 사용한다.

1. 추진 배경
2. 추진 경과
3. 주요 내용
4. 향후 추진 계획
5. 붙임

상위 목차를 5개보다 많이 벌리지 않는다. 사용자가 별도로 요구하지 않으면 `검토 결과`, `운영 방안`, `수요조사 결과`, `배분안` 같은 항목을 상위 목차로 따로 빼지 않는다.

## 3. 중요 규칙: 계약 결과 + 운영 계획 결합 문서

사용자 요청에 아래 요소가 함께 들어 있으면, 이 유형을 우선 적용한다.

- 계약 체결 결과
- 추진 경과
- 보안 검토 또는 사전 검토 결과
- 수요조사 결과
- 운영 계획
- 배분안 또는 선정안

이 경우 기본 구조는 아래처럼 잡는다.

```text
1. 추진 배경
2. 추진 경과
3. 주요 내용
  가. 계약 체결 결과
  나. 시범운영 또는 운영 계획
    - 수요조사 결과
    - 전문가 검토를 통한 우선 선정
    - 배분안 및 운영 계획
4. 향후 추진 계획
붙임
```

핵심 규칙은 아래와 같다.

- `계약 체결 결과`와 `운영 계획`은 보통 `주요 내용` 아래 `가`, `나`로 묶는다.
- `수요조사 결과`, `전문가 검토`, `배분안`은 `나. 운영 계획` 아래 세부 항목으로 넣는다.
- 상위 목차를 `계약 체결 결과`, `수요조사 결과`, `전문가 검토`, `배분안`으로 따로 승격하지 않는다.
- 사용자가 한 번 구조를 다듬어 준 경우, 그 구조를 우선 기준으로 삼는다.

## 4. 문서 유형 판정

문서 유형은 아래처럼 단순하게 판정한다.

- 검토보고: 대안 비교와 판단이 중심일 때
- 계획보고: 앞으로 할 일과 일정이 중심일 때
- 결과보고: 완료 사실과 주요 결과가 중심일 때
- 결합형 보고: 결과보고와 계획보고가 함께 있을 때

이번 스킬에서 특히 자주 쓰는 것은 `결합형 보고`다. 결합형 보고에서는 상위 목차를 더 쪼개지 말고, `주요 내용` 안에서 결과와 계획을 나눠 담는다.

## 5. 작성 방식

- 첫 문단에서 문서 취지와 보고 목적을 한 문단으로 정리한다.
- `추진 경과`는 날짜순으로 정리한다.
- `주요 내용`은 판단이 필요한 항목부터 배치한다.
- `향후 추진 계획`은 다음 조치, 일정, 결재 필요사항이 드러나야 한다.
- `붙임`은 본문에서 언급한 자료만 정리한다.

## 6. 문체

- 기본 문체는 공공기관 결재문서용 개조식으로 작성한다.
- 문장 종결은 `~함`, `~임`, `~필요`, `~예정`, `~추진`, `~검토` 중심으로 정리한다.
- 본문에서 과도한 설명체, 구어체, 광고식 표현을 쓰지 않는다.
- `검토 필요`만 쓰지 말고 무엇을 누가 확인해야 하는지 드러낸다.

## 7. 초안 점검

초안 작성 후 아래를 확인한다.

- 상위 목차가 과하게 늘어나지 않았는가
- `주요 내용` 아래에 세부 쟁점이 제대로 묶였는가
- `추진 배경`, `추진 경과`, `주요 내용`, `향후 추진 계획`, `붙임` 흐름이 유지되는가
- 날짜, 예산, 계약명, 기관명, 붙임명이 본문과 충돌하지 않는가
- 결재권자가 바로 판단할 수 있는 문장 순서인가

## 8. 출력 기본형

사용자가 별도 형식을 주지 않으면 아래 순서로 출력한다.

```markdown
## 작성 방향

- 문서 유형:
- 보고 목적:
- 기본 목차:
- 핵심 판단:

## 초안

[결재문서 초안]

## 보완 필요사항

- [확인 필요 정보]
```
