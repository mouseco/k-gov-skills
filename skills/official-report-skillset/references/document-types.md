# 공문서 보고서 유형별 권장 구조

## 1. 검토보고

목적: 의사결정권자가 대안 중 하나를 판단하거나 승인하도록 돕는다.

권장 구조:

1. 검토 배경
2. 주요 쟁점
3. 대안 비교
4. 검토 의견
5. 향후 조치

필수 요소:

- 판단해야 할 질문
- 검토 기준
- 대안별 장단점
- 추천안과 이유
- 시행 조건과 리스크

## 2. 계획보고

목적: 앞으로 추진할 사업·과제의 실행계획을 제시한다.

권장 구조:

1. 추진 배경
2. 추진 목표
3. 주요 추진내용
4. 추진 일정 및 역할
5. 기대효과 및 리스크

필수 요소:

- 추진 필요성
- 목표와 성과지표
- 담당 부서·협조 부서
- 일정
- 예산·자원
- 점검 기준

## 3. 결과보고

목적: 추진 결과와 성과, 한계, 후속 조치를 보고한다.

권장 구조:

1. 추진 개요
2. 추진 결과
3. 성과 및 한계
4. 개선사항
5. 향후 계획

필수 요소:

- 당초 목표 대비 결과
- 정량·정성 성과
- 미흡 사항
- 개선 조치
- 후속 일정

## 4. 간부보고

목적: 짧은 시간 안에 핵심 판단을 지원한다.

권장 구조:

1. 결론 또는 요청사항
2. 핵심 근거
3. 쟁점 또는 대안
4. 조치계획

필수 요소:

- 첫 문단 결론
- 결정이 필요한 사항
- 핵심 근거 2~3개
- 리스크 또는 유의사항
- 요청사항

## 5. 회의결과 보고

목적: 논의 내용보다 결정사항과 후속 조치를 명확히 남긴다.

권장 구조:

1. 회의 개요
2. 주요 논의
3. 결정사항
4. 후속 조치

필수 요소:

- 일시·장소·참석자
- 주요 논의 요지
- 결정사항
- 담당자와 기한
- 보류사항

## 6. 동향보고

목적: 외부 변화가 기관 업무에 주는 영향을 정리한다.

권장 구조:

1. 핵심 동향
2. 주요 내용
3. 우리 기관 영향
4. 대응 방향
5. 추가 확인사항

필수 요소:

- 중요한 변화와 단순 소식의 구분
- 우리 기관과의 관련성
- 기회와 위험
- 대응 필요성
- 관찰 지표
