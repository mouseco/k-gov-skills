# 공문서 보고서 유형별 권장 구조

## 1. 검토보고

목적: 대안 비교와 판단이 중심인 문서

권장 구조:

1. 추진 배경
2. 검토 내용
3. 대안 비교
4. 검토 의견
5. 향후 조치

## 2. 계획보고

목적: 앞으로 추진할 일과 일정, 역할, 운영방안을 정리하는 문서

권장 구조:

1. 추진 배경
2. 추진 목적
3. 주요 내용
4. 추진 일정
5. 기대효과 또는 유의사항

## 3. 결과보고

목적: 이미 완료된 사실과 주요 결과를 보고하는 문서

권장 구조:

1. 추진 배경
2. 추진 경과
3. 주요 결과
4. 시사점
5. 향후 계획

## 4. 결합형 보고

목적: 완료된 결과와 앞으로의 운영계획을 함께 결재받는 문서

권장 구조:

1. 추진 배경
2. 추진 경과
3. 주요 내용
4. 향후 추진 계획
5. 붙임

적용 예시:

- 계약 체결 결과보고 및 운영 계획
- 선정 결과보고 및 후속 추진 계획
- 시범사업 추진 결과와 확대 운영 계획

세부 구성 원칙:

- `주요 내용` 아래에서 결과와 계획을 나눈다.
- `가. 계약 체결 결과`
- `나. 운영 계획`
- `나. 운영 계획` 아래에 수요조사, 전문가 검토, 배분안, 운영 기준을 넣는다.

금지 규칙:

- `계약 체결 결과`, `수요조사 결과`, `전문가 검토`, `배분안`을 상위 목차로 따로 늘리지 않는다.
- 사용자가 별도로 요구하지 않으면 상위 목차를 5개 이상으로 벌리지 않는다.

## 5. 회의결과 보고

목적: 회의 내용보다 결정사항과 후속 조치를 정리하는 문서

권장 구조:

1. 회의 개요
2. 주요 논의사항
3. 결정사항
4. 후속 조치

## 6. 간단 보고

목적: 짧은 메모 수준으로 결론과 조치만 빠르게 보고하는 문서

권장 구조:

1. 결론 또는 요청사항
2. 핵심 근거
3. 조치 계획
