# Verbatim Authoring Rules

- 사용자가 본문 원고를 직접 제공하면 원문 정보를 최대한 보존한다
- 다만 원문을 그대로 덤프하지 말고, 문서 양식과 개조식 표현에 맞게 재구성할 수 있다
- 재구성의 원칙은 요약보다 보존 우선이다. 핵심 사실, 수치, 고유명사, 구분 구조, 번호 체계는 가능한 한 유지한다
- 원문에 있는 제목, 번호, 글머리표, 괄호, 영문 병기, 구분선은 가능한 한 그대로 유지한다
- 문장 부호는 임의로 추가하거나 삭제하지 않는다. 사용자가 특정 문장부호 금지 규칙을 주면 그 규칙을 우선 반영한다
- HWPX 양식에 슬롯이 부족하면 내용을 억지로 축약하지 말고, 기존 문단 스타일을 복제하거나 유사 슬롯을 추가해 전체 내용을 수용한다
- 슬롯 추가는 LLM이 문맥을 보고 수행하되, 양식의 위계(제목/본문/하위 bullet/비고)를 깨지 않도록 같은 스타일 계열 안에서 확장한다
- 최종 산출물은 '원문 최대 보존 + 양식 구조 준수 + 개조식 표현 유지'의 절충안을 목표로 한다
- 생성 후 `Preview/PrvText.txt`와 `Contents/section*.xml` 모두에 핵심 구간이 존재하는지 검증한다
