# transport-receipt-collector

`transport-receipt-collector`는 공공기관 출장·여비·교통비 정산에 필요한 교통 영수증을 PDF와 PNG 증빙 파일로 정리하는 스킬이다.

## 해결하는 문제

출장 정산에서는 같은 교통비라도 제출처에 따라 PDF가 필요할 때도 있고, 이미지 첨부만 가능한 경우도 있다. 이 스킬은 하이패스, 코레일, SRT 같은 교통 영수증을 같은 파일명 규칙과 월별 폴더 구조로 모아 검토와 제출을 쉽게 만든다.

v0.1은 하이패스를 1차 대상으로 한다.

## 언제 쓰는지

- 하이패스 사용내역 영수증을 월별로 저장해야 할 때
- 출장비·여비 정산용 교통비 증빙을 준비할 때
- PDF와 PNG를 함께 만들어야 할 때
- 코레일·SRT 영수증 수집 기능을 같은 구조로 확장하려 할 때

## 입력과 출력

입력:

- provider: `hipass`, `korail`, `srt`, `all`
- 시작일과 종료일
- 저장 폴더
- 선택 항목: 전체 저장 또는 특정 건 저장

출력:

- PDF 영수증
- PNG 영수증 이미지(1건 기준 하이패스 사각형 영수증 영역만 크롭)
- 성공·실패 요약
- 실패한 항목의 사유

예시 출력 구조:

```text
outputs/receipts/2026-05/
  2026-05-03_hipass_서울TG-동대구TG_12800.pdf
  2026-05-03_hipass_서울TG-동대구TG_12800.png
```

## 기본 workflow

1. provider와 기간을 확인한다.
2. 하이패스는 기본적으로 로컬 환경변수의 ID/PW로 로그인한다.
3. 추가 본인확인이 나오면 자동화를 중단하고 사용자가 직접 브라우저에서 처리한다.
4. provider별 사용내역 또는 영수증 목록을 조회한다.
5. 영수증 출력 화면에 진입한다.
6. PDF와 PNG를 같은 base name으로 저장한다.
7. 저장된 파일과 실패 항목을 요약한다.

## 하이패스 v0.1

하이패스는 ID/비밀번호 자동 로그인을 기본값으로 한다.

- 기본적으로 `C:\Users\mouse\.openclaw\.env`를 로드하고, `KGOV_HIPASS_ID`, `KGOV_HIPASS_PW`를 읽는다.
- 로그인 후 사용내역 조회 화면에 접근한다.
- 날짜 범위를 적용해 조회한다.
- 대상 건의 영수증 출력 화면 또는 팝업을 연다.
- PDF와 PNG를 저장한다.

브라우저에 이미 직접 로그인한 세션을 쓰려면 `--auth-mode session`을 사용한다. 추가 본인확인이 나오면 자동화를 중단한다.

v2 headless 모드는 `--headless`로 실행한다. 이 모드는 ID/PW 자동 로그인 전용이며, 브라우저 세션 재사용 방식과 함께 쓰지 않는다.

## 실패 모드와 보완 방법

- ID/PW 환경변수가 없으면 값을 로컬 환경변수에 설정한다.
- 자동 로그인 실패나 세션 만료가 발생하면 직접 로그인 세션 방식으로 재시도할 수 있다.
- 추가 본인확인이 나오면 사용자가 직접 처리한다.
- 조회 결과가 없으면 기간, 날짜 기준, 카드 조건을 다시 확인한다.
- PNG 저장이 실패하면 PDF 첫 페이지를 PNG로 렌더링한다.
- 영수증 출력이 제한되는 조건이면 공식 사이트 안내를 따른다.

## 보안·민감정보 주의사항

- 계정 비밀번호, 인증번호, 인증서 파일, 인증서 비밀번호, 카드번호 원문은 저장소나 로그에 남기지 않는다.
- CAPTCHA 인식, 2차 인증 자동 통과, 공동인증서 자동 조작은 공개 스킬 범위 밖이다.
