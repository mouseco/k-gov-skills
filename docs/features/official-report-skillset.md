# 공공 보고서 작성 가이드

공공기관 보고서 초안이 필요할 때 쓰는 스킬입니다. 메모, 회의 결과, 사업 아이디어, 지시사항을 받아서 **검토보고·계획보고·결과보고·간부보고** 형태로 정리합니다.

## 이 기능으로 할 수 있는 일

- 문서가 검토보고인지, 계획보고인지, 결과보고인지 먼저 판별
- 독자와 의사결정 포인트에 맞춰 목차 구성
- 공공기관 개조식 문체로 초안 작성
- 사실, 해석, 판단, 리스크, 후속조치 구분
- 누락된 근거, 책임자, 일정, 예산, 의사결정 요청사항 표시
- 쟁점이 크면 `deep-research-pro` 흐름으로 근거조사 연결

## 먼저 알아둘 점

- 이 스킬은 예쁜 문장을 만드는 스킬이 아니라 **의사결정용 문서 구조를 잡는 스킬**입니다.
- 근거 없는 수치, 일정, 법령명, 예산을 임의로 만들지 않습니다.
- 승인 문서인지 공유 문서인지에 따라 구조가 달라집니다.
- 실제 기관명, 개인명, 내부 예산자료는 사용자가 제공한 범위 안에서만 다룹니다.

## 입력

다음 중 일부만 있어도 시작할 수 있습니다.

- 주제 또는 원문 메모
- 문서 유형 또는 예상 독자
- 현재 상황, 문제, 추진 배경
- 일정, 담당, 예산, 관련 근거
- 원하는 산출물 길이: 1쪽 요약, 본문형 보고서, 간부 보고 메모 등

정보가 부족하면 본문에 `확인 필요`로 남기고, 근거가 필요한 항목을 따로 표시합니다.

## 기본 흐름

1. 요청 목적을 확인합니다. 승인, 공유, 검토, 보고 중 무엇인지 나눕니다.
2. 문서 유형을 정합니다.
3. 보고서의 독자와 의사결정 포인트를 잡습니다.
4. 목차와 문단 위계를 구성합니다.
5. 공공기관 개조식 문장으로 초안을 씁니다.
6. 근거·누락·리스크·후속조치를 점검합니다.
7. 한글 문장과 표현을 다듬습니다.

쟁점이 크거나 출처 있는 판단이 필요하면 먼저 심층조사를 진행합니다.

## 사용 예시

```text
이 메모를 부장님 보고용 검토보고서 초안으로 정리해줘.
```

```text
AI 도입 방안 1쪽 보고서로 써줘. 근거가 부족한 부분은 확인 필요로 표시해줘.
```

```text
회의 결과를 바탕으로 향후 조치 중심의 결과보고서 만들어줘.
```

## 결과 확인 포인트

- 문서 목적이 승인인지 공유인지 분명한가
- 핵심 판단이 앞부분에 있는가
- 배경 설명만 길고 추천안이 비어 있지 않은가
- 담당자, 일정, 산출물, 점검 기준이 빠지지 않았는가
- 숫자와 법령·지침 근거가 실제 출처와 연결되는가
- `확정`, `추진 예정`, `필요` 같은 표현이 원문 근거 없이 쓰이지 않았는가

## 주의할 점

- 공공문서 문체를 흉내 내는 것과 실제 의사결정 문서를 만드는 것은 다릅니다.
- 대안 비교가 필요한 문서에서 배경 설명만 길게 쓰면 실패입니다.
- 사실관계가 불확실하면 단정하지 말고 `확인 필요`로 남깁니다.
- 공개 예시에는 실제 기관명, 개인명, 내부 의사결정 내용, 예산 세부자료를 넣지 않습니다.
