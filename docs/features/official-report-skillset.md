# 공공 보고서 작성 가이드

`official-report-skillset`은 공공기관 결재문서를 한 번에 구조화하기 위한 스킬이다. 메모, 추진 경과, 계약 내용, 운영 계획, 배분안, 붙임 자료를 받아 공공기관 보고서 형식으로 정리할 때 사용한다.

## 핵심 동작

- 문서 목적과 유형을 먼저 판정한다.
- 상위 목차를 과하게 늘리지 않는다.
- 세부 쟁점은 `주요 내용` 아래에 묶는다.
- 결재권자가 바로 판단할 수 있게 `추진 배경 → 추진 경과 → 주요 내용 → 향후 추진 계획 → 붙임` 흐름을 우선 적용한다.

## 기본 목차 규칙

공공기관 내부 결재문서의 기본 상위 목차는 아래 순서를 우선 사용한다.

1. 추진 배경
2. 추진 경과
3. 주요 내용
4. 향후 추진 계획
5. 붙임

사용자가 별도 형식을 주지 않으면, `검토 결과`, `운영 방안`, `수요조사 결과`, `배분안` 같은 항목을 상위 목차로 따로 빼지 않는다.

## 결합형 보고 기본값

계약 체결 결과와 운영 계획이 함께 있는 문서는 아래 구조를 기본값으로 사용한다.

```text
1. 추진 배경
2. 추진 경과
3. 주요 내용
  가. 계약 체결 결과
  나. 시범운영 또는 운영 계획
    - 내부망 AI 도입 수요조사 결과
    - 전문가 검토를 통한 우선 배분 대상 선정
    - 라이선스 배분안 및 운영 계획
4. 향후 추진 계획
붙임
```

핵심은 상위 목차를 늘리지 않는 것이다. `계약 체결 결과`, `수요조사 결과`, `전문가 검토`, `배분안`은 보통 `주요 내용` 아래에 넣는다.

## 출력 품질 기준

- 첫 문단에서 보고 목적이 드러나야 한다.
- `추진 경과`는 날짜순으로 정리한다.
- `향후 추진 계획`에는 다음 조치와 결재 필요사항이 보여야 한다.
- 날짜, 수치, 계약명, 예산, 붙임 자료가 본문과 충돌하지 않아야 한다.
