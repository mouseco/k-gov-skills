# official-report-skillset

## 해결하는 문제

공공기관 보고서 작성 요청을 받았을 때 문서 유형, 독자, 판단사항, 근거, 실행계획을 먼저 정리해 의사결정용 초안으로 바꾸는 스킬이다.

## 언제 쓰는가

- 공문서, 검토보고서, 계획보고서, 결과보고서, 간부보고, 회의결과 보고 초안 작성
- 정책 보고서 구조화
- 공공기관 문체·개조식 문장 정리
- 보고서 논리, 누락, 리스크 점검

## 입력

- 주제 또는 원문 메모
- 문서 유형 또는 예상 독자
- 내부 현황, 일정, 담당, 예산, 근거 자료
- 필요 시 출처 있는 근거조사 요청

## 출력

기본 출력은 다음 순서를 따른다.

1. 작성 방향
2. 문서 유형
3. 핵심 근거와 가정
4. 보고서 초안
5. 보완 필요사항

## 기본 workflow

1. 근거 확인 필요 여부 판단
2. 문서 유형 판별
3. 작성 기법 선택
4. 공공기관 개조식 초안 작성
5. 논리·누락·리스크 점검
6. 한글 문장 교정

쟁점이 크거나 출처 있는 종합 판단이 필요하면 `deep-research-pro` 방식으로 근거를 먼저 모은다.

## 실패 모드

- 근거 없는 숫자·일정을 단정함
- 문서 목적이 승인인지 공유인지 불명확함
- 대안과 추천안 없이 배경 설명만 길어짐
- 책임자, 일정, 산출물, 점검 기준이 빠짐

## 보안 주의

실제 기관명, 내부 의사결정 내용, 개인명, 예산 세부자료는 사용자가 제공한 범위 안에서만 다루고 공개 예시로 재사용하지 않는다.
