# 한국 법령 검색 가이드

`korean-law-search`는 국가법령정보센터/법제처 Open API 계열과 `korean-law-mcp`를 활용해 한국 법령, 조문, 판례, 유권해석, 자치법규를 조회하는 스킬입니다.

이 스킬은 `NomaDamas/k-skill` 계열 원본을 공공기관 보고서 근거조사 흐름에 맞춰 가져와 일부만 정리한 파생·적응본입니다. 원 출처와 사용 도구의 권리는 각 원 저작자와 서비스에 있습니다.

## 이 기능으로 할 수 있는 일

- 법령명 검색
- 법률·시행령·시행규칙 조문 본문 조회
- 판례 검색
- 법령해석례 검색
- 자치법규 검색
- 여러 법령에 걸친 종합 조사
- 보고서에 넣을 법령 근거 문장 확인

## 기본 경로

기본은 `korean-law-mcp`입니다.

주요 조회:

- `search_law`: 법령명 검색
- `get_law_text`: 조문 본문 조회
- `get_batch_articles`: 여러 조문 일괄 조회
- `search_precedents`: 판례 검색
- `search_interpretations`: 법령해석례 검색
- `search_ordinance`: 자치법규 검색
- `search_all`: 통합 검색

법제처 Open API 키가 필요한 로컬 경로에서는 `LAW_OC` 또는 사용자가 제공한 API key를 사용합니다. 원격 MCP 또는 현재 OpenClaw 도구가 이미 연결된 경우 별도 키 없이 조회될 수 있습니다.

## fallback

기본 경로가 동작하지 않을 때만 법망(`https://api.beopmang.org`)을 fallback으로 사용합니다.

## 사용 예시

```text
한국장학재단법 찾아줘.
```

```text
취업후상환법 제1조, 제2조, 제3조를 확인해줘.
```

```text
공공기관 AI 도입 근거로 쓸 수 있는 법령 조문을 찾아줘.
```

## 출력 원칙

1. 먼저 정식 법령명을 확인합니다.
2. 법령ID, MST, 공포일, 법령 구분을 기록합니다.
3. 조문 원문과 요약을 분리합니다.
4. 법률·시행령·시행규칙을 혼동하지 않습니다.
5. 보고서에 쓸 때는 법령명, 조문 번호, 핵심 문구를 함께 적습니다.
6. 법률 자문처럼 단정하지 않고, 실제 판단이 필요한 경우 검토 필요로 표시합니다.

## 확인 예시

- `한국장학재단법` 검색 시 정식 법령명은 `한국장학재단 설립 등에 관한 법률`입니다.
- `취업후상환법` 검색 시 정식 법령명은 `취업 후 학자금 상환 특별법`입니다.

## 주의사항

- 법령은 시행일과 개정일에 따라 내용이 달라질 수 있습니다.
- 과거 시점 기준 검토가 필요하면 연혁법령 또는 조문 이력을 따로 확인합니다.
- 공공기관 내규는 국가법령정보센터에 일부만 있을 수 있으므로, 기관 내부규정은 ALIO 내부규정 메뉴를 함께 확인합니다.
- 공개 저장소에는 API key나 인증 정보를 기록하지 않습니다.
