# 심층 리서치 가이드

공공기관 보고서에 넣을 법령, 지침, 공식자료, 통계, 유사 사례를 출처와 함께 조사할 때 쓰는 스킬입니다. 단순 검색 결과가 아니라 **근거 있는 판단 브리프와 보고서 근거 메모**를 만드는 것이 목표입니다.

## 이 기능으로 할 수 있는 일

- 조사 주제를 3~5개 연구 질문으로 분해
- 법령·시행령·고시·행정규칙·지침 확인
- 정부·공공기관 공식자료, 첨부 PDF, 통계 우선 조사
- 국회, 감사원, 예산정책처, 입법조사처, 연구기관 보고서 확인
- 유사기관 사례와 정책 동향 비교
- 출처, 기준일, PDF 확인 여부, 한계, 추가 확인사항을 함께 정리
- 공통으로 확인된 점, 엇갈리는 쟁점, 반대 근거, 결정 포인트 정리
- 보고서 본문에 넣을 수 있는 근거 문장으로 재구성

## 출처와 소유권 주의

이 스킬은 mouseco의 순수 창작 스킬이 아니라 ClawHub `deep-research-pro`를 Windows/OpenClaw 환경과 공공문서 리서치 목적에 맞게 조정한 적응본입니다.

자세한 출처와 수정 범위는 `docs/attribution.md`를 따릅니다.

## 먼저 알아둘 점

- 검색 스니펫만 보고 결론을 내리지 않습니다.
- 핵심 공식자료가 PDF 첨부 중심이면 HTML 게시글만 읽고 끝내지 않습니다.
- 블로그나 언론 기사보다 원출처를 먼저 확인합니다.
- 숫자는 기준일, 모집단, 산식이 중요합니다.
- 단일 출처 주장은 일반 사실처럼 쓰지 않고 한계를 표시합니다.
- 성공사례만 보지 않고 실패 조건과 반대 근거를 함께 봅니다.
- 최종 답변은 조사 로그가 아니라 읽기 쉬운 판단 브리프로 씁니다.
- 로그인 자료, 유료 자료, 내부문서, 비공개 PDF는 자동 수집하지 않습니다.

## 입력

- 조사 주제
- 조사 목적: 의사결정, 보고서 근거, 정책 검토 등
- 범위: 기간, 국가, 기관, 산업, 법령, 비교 대상
- 원하는 산출물 형식: 요약 메모, 보고서 근거, 출처 목록 등

## 기본 흐름

1. 조사 목적과 사용처를 정합니다.
2. 연구 질문 3~5개로 나눕니다.
3. 공식 출처 우선순위를 정합니다.
4. `web_search`로 후보를 찾습니다.
5. `web_fetch`, 브라우저, PDF 추출, 법령 도구로 본문을 확인합니다.
6. 핵심 첨부 PDF가 있으면 최소 1개 이상 본문 또는 앞쪽 핵심 페이지를 확인합니다.
7. 사실, 의미, 판단, 한계를 분리합니다.
8. 반대 근거와 실패 조건을 검토합니다.
9. 공통으로 확인된 점, 엇갈리거나 조심할 점, 결정 포인트를 정리합니다.
10. 출처 목록, PDF 확인 여부, 추가 확인 필요사항을 남깁니다.

## 출처 우선순위

1. 법령·시행령·고시·행정규칙·지침
2. 정부·부처·공공기관 공식자료
3. 통계청·공공데이터·정부 통계
4. 국회·감사원·예산정책처·입법조사처·연구기관 보고서
5. 유사기관 사례
6. 신뢰 가능한 언론·전문 매체

## 사용 예시

```text
공공기관 AI 도입 시 개인정보보호 쟁점을 출처 달아서 조사해줘.
```

```text
이 사업계획서에 넣을 법령·정부 지침·유사기관 사례를 정리해줘.
```

```text
최근 3년간 공공기관 생성형 AI 활용 사례를 보고서 근거 메모로 만들어줘.
```

## 출력 형식

대화 답변은 다음 구성을 권장합니다.

1. 결론
2. 핵심 발견
3. 상세 분석
4. 공통으로 확인된 점
5. 엇갈리거나 조심할 점
6. 결정 포인트
7. 출처

파일 보고서는 위 구조에 조사 방법, PDF 본문 확인, 출처 등급, 추가 확인 필요사항을 붙입니다.

## 결과 확인 포인트

- 원출처를 확인했는가
- 핵심 PDF 첨부의 본문을 확인했는가
- 출처명, 발행기관, 발행일 또는 기준일이 있는가
- 통계의 모집단과 기준이 분명한가
- 사실과 해석이 섞이지 않았는가
- 사실이 판단으로 연결됐는가
- 반대 근거와 실패 조건을 확인했는가
- 결정 포인트가 남아 있는가
- 보고서에 쓸 수 있는 문장으로 정리됐는가
- 한계와 추가 확인 필요사항을 숨기지 않았는가

## 주의할 점

- 출처 없는 일반론을 보고서 근거처럼 쓰지 않습니다.
- 비공개 자료와 공개 자료의 경계를 구분합니다.
- upstream 스킬 출처를 mouseco 순수 제작물처럼 표시하지 않습니다.
- `자세한 내용은 첨부 참고` 형태의 공식 게시글은 첨부 PDF 확인 전까지 본문 확인이 끝난 것으로 보지 않습니다.
- 대화 답변에서 영어식 제목을 기본값으로 쓰지 않고, `핵심 요약`, `핵심 발견`, `결정 포인트`처럼 한글 제목을 씁니다.
