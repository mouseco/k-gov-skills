# deep-research-pro

## 해결하는 문제

공공기관 보고서에 들어갈 법령·지침·공식자료·통계·사례 근거를 출처와 함께 조사하고, 의사결정에 쓸 수 있는 요약으로 정리하는 스킬이다.

## 출처와 소유권 주의

이 스킬은 mouseco의 순수 창작 스킬이 아니라 ClawHub `deep-research-pro`를 Windows/OpenClaw 환경과 공공문서 리서치 목적에 맞게 조정한 적응본이다. 자세한 출처와 수정 범위는 `docs/attribution.md`를 따른다.

## 언제 쓰는가

- “출처 달아서 깊게 조사해줘”
- 정책·제도·사업 타당성 근거 조사
- 법령·지침·공식자료·통계·유사기관 사례 비교
- 보고서용 근거 메모 작성
- 단일 검색 답변으로는 부족한 쟁점 정리

## 입력

- 조사 주제
- 조사 목적: 의사결정, 보고서 근거, 정책 검토 등
- 범위: 기간, 국가, 기관, 산업, 법령, 비교 대상
- 원하는 산출물 형식

## 출력

- Executive Summary
- 연구 질문 3~5개
- 핵심 쟁점별 사실·해석·근거·판단
- 출처 목록
- 조사 방법
- 한계와 추가 확인 필요사항

## 기본 workflow

1. 조사 목적과 범위 정리
2. 연구 질문 3~5개로 분해
3. 공식 출처 우선순위 설정
4. `web_search`로 후보 확보
5. `web_fetch` 또는 브라우저/PDF/법령 도구로 본문 확인
6. 단일 출처 주장과 한계를 표시
7. 보고서 반영용 근거 메모 작성

## 출처 우선순위

공공기관·정책·제도 조사에서는 다음 순서를 우선한다.

1. 법령·시행령·고시·행정규칙·지침
2. 정부·부처·공공기관 공식자료
3. 통계청·공공데이터·정부 통계
4. 국회·감사원·예산정책처·입법조사처·연구기관 보고서
5. 유사기관 사례
6. 신뢰 가능한 언론·전문 매체

## 실패 모드

- 검색 스니펫만 보고 결론을 냄
- 블로그·언론 기사만 모으고 원출처를 확인하지 않음
- 숫자의 기준일·모집단·산식을 확인하지 않음
- 단일 출처 주장을 일반 사실처럼 씀
- upstream 스킬 출처를 mouseco 순수 제작물처럼 표시함

## 보안 주의

로그인 자료, 유료 자료, 내부문서, 비공개 PDF는 자동 수집하지 않는다. 공개 출처와 사용자가 제공한 자료의 경계를 구분한다.
