# ALIO 기관별 공시 상세 확인 가이드

ALIO 공공기관 경영정보 공개시스템(`alio.go.kr`)에서 공공기관별 공시 상세내용을 확인해 보고서 근거나 비교 메모로 정리하는 스킬입니다.

오늘 기준 범위는 **ALIO 본공시의 기관별 공시 상세내용 확인**입니다. ALIO PLUS API, 행사·시설·사업 안내, 오픈데이터 대량 수집 자동화는 이번 스킬의 기본 범위에서 제외합니다.

## 이 기능으로 할 수 있는 일

- 특정 공공기관의 기관별 공시 상세내용 확인
- 일반현황, 기관운영, 임직원, 임원, 재무, 주요사업 등 항목별 확인
- 여러 기관의 같은 공시 항목 비교
- 내부·외부 감사결과, 감사원·주무부처 지적사항, 첨부자료 확인
- 내부규정 목록과 첨부 규정 파일 확인
- 공시 항목별 기준연도, 공시일, 단위, 주석 확인
- 보고서에 붙일 수 있는 출처 포함 근거 메모 작성

## k-dart와 비슷한 점

`k-dart`가 기업명을 식별하고 DART 공시 항목을 조회하듯, 이 스킬은 공공기관명을 식별한 뒤 ALIO 기관별 공시 상세 항목을 확인합니다.

작업 흐름은 다음과 같습니다.

1. 기관명 식별
2. ALIO 기관별 공시 진입
3. 공시 항목 선택
4. 상세내용 확인
5. 기준연도·공시일·단위·출처 포함 요약

## 먼저 알아둘 점

- ALIO 본공시를 1차 출처로 봅니다.
- ALIO PLUS는 이번 스킬의 기본 출처가 아닙니다.
- 수치 자료는 기준연도, 공시차수, 공시일, 단위가 중요합니다.
- 기관명 후보가 여러 개면 주무부처와 기관유형으로 구분합니다.
- 검색 결과가 없다고 해서 관련 정보가 존재하지 않는다고 단정하지 않습니다.

## 입력

- 기관명 또는 기관 후보
- 확인할 공시 항목: 일반현황, 임직원 수, 재무정보, 주요사업 등
- 기준연도 또는 비교 기간
- 원하는 출력: 요약 메모, 비교 정리, 출처 목록, 보고서 반영 문장

## 기본 흐름

1. 조사 목적과 필요한 공시 항목을 정합니다.
2. ALIO 기관별 공시에서 대상 기관을 찾습니다.
3. 기관명, 주무부처, 기관유형을 확인합니다.
4. 필요한 공시 항목의 상세내용을 엽니다.
5. 기준연도, 공시일, 수치 단위, 주석, 첨부파일 여부를 확인합니다.
6. 내부규정 요청은 ALIO 내부규정 목록에서 기관명으로 조회하고 상세 첨부파일을 확인합니다.
7. 감사·유출·징계처럼 민감한 요청은 실제 발생 확인, 위험/우려, 단순 점검, 모범사례를 구분합니다.
8. 사실, 해석, 활용 판단, 추가 확인사항을 나눠 정리합니다.
9. 출처 URL과 확인일을 함께 남깁니다.

## 사용 예시

```text
○○공단의 ALIO 기관별 공시 상세내용에서 일반현황, 기관유형, 주무부처, 최근 기준연도 임직원 수를 확인해줘.
```

```text
장학·교육지원 관련 공공기관 3곳의 임직원 수와 재무정보를 ALIO 기관별 공시 기준으로 비교해줘.
```

```text
이 기관의 주요사업 공시 상세내용을 보고서 근거 문장으로 정리해줘.
```

```text
○○공단 내부·외부 감사결과에서 최근 5년간 '유출' 관련 지적사항을 찾아 실제 유출과 유출 우려를 구분해줘.
```

```text
○○공단 ALIO 내부규정 목록을 분야별로 정리하고 인사규정 최신 첨부파일을 확인해줘.
```

## 출력 형식

기본 출력은 다음 구성을 권장합니다.

1. 요약
2. 확인한 기관과 공시 항목
3. 공시 상세 확인 결과
4. 보고서 활용 판단
5. 출처 목록
6. 추가 확인 필요사항

## 결과 확인 포인트

- ALIO 기관별 공시 상세내용을 실제로 확인했는가
- 기관명, 주무부처, 기관유형을 확인했는가
- 기준연도, 공시차수, 공시일 또는 자료 기준일을 남겼는가
- 수치 단위와 기간을 적었는가
- 기관 간 비교 시 같은 기준연도와 같은 공시 항목을 사용했는가
- ALIO PLUS를 ALIO 본공시처럼 표현하지 않았는가

## 보안·민감정보 주의사항

- 사용자 계정, 내부망, 비공개 기관자료 접근을 요구하지 않습니다.
- 공개 공시자료만 사용합니다.
- 공개 저장소에는 검색 결과 원문 덤프나 개인정보가 포함된 파일을 커밋하지 않습니다.
