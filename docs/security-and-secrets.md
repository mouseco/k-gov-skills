# 보안·시크릿·공개자료 기준

`k-gov-skills`는 공공문서와 HWPX 자동화를 다루므로 일반 스킬 저장소보다 공개 기준을 엄격하게 둔다.

## 커밋 금지 자료

- 실제 기관 내부문서 원본
- 개인명, 이메일, 전화번호, 주소, 계좌, 사번 등 개인정보
- 비공개 조직명, 내부 부서명, 문서번호, 결재선
- API 키, 토큰, 쿠키, 비밀번호, 세션 파일
- 로그인 후 받은 원문, 유료 자료, 접근 제한 자료
- 생성 결과물, 임시 파일, 압축 해제 폴더

## 허용 자료

- 공개 배포용으로 정리한 HWPX 템플릿
- 가상 기관·가상 주제 기반 예시 JSON
- 공공문서 작성 규칙과 HWPX 구조 참고자료
- 공개 웹페이지, 공식 문서, 오픈소스 프로젝트 링크
- 실행 검증용 최소 스크립트

## HWPX 템플릿 공개 기준

HWPX 파일을 커밋하기 전에 확인한다.

1. 파일명과 본문에 실제 기관명·개인명·문서번호가 없는가
2. `Preview/PrvText.txt`에 민감 문구가 남아 있지 않은가
3. `Contents/section*.xml`에 내부자료가 남아 있지 않은가
4. `BinData/`에 내부 이미지·직인·서명이 포함되어 있지 않은가
5. 공개 배포 목적의 더미 문구 또는 중립 표현으로 치환되었는가

## 시크릿 처리

이 저장소의 스킬은 기본적으로 시크릿 없이 동작해야 한다. 외부 API 키가 필요한 스킬을 추가할 경우:

- 시크릿은 저장소에 두지 않는다.
- 환경변수 이름은 `KGOV_<SERVICE>_<NAME>` 또는 해당 upstream 표준을 따른다.
- 시크릿이 없으면 우회하지 말고 필요한 값 이름을 사용자에게 알려준다.
- 프록시를 쓰는 경우 upstream 키는 서버에만 둔다.

## 외부·파생 스킬

외부 스킬을 수정한 경우:

- 원 출처, 설치 버전, 수정 범위를 `docs/attribution.md`에 적는다.
- 라이선스를 확인하지 못한 경우 `license: MIT`로 단정하지 않는다.
- 공개 배포 시 원저작자 권리와 upstream 조건을 우선한다.

## 검증 명령

```powershell
python -X utf8 scripts\validate_skills.py
```

검증은 보조 수단이다. 민감정보 공개 가능성은 최종적으로 사람이 다시 확인해야 한다.
